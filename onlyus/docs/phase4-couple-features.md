# Phase 4 — "Us" Couple Features

## Implemented in `src/features/us/UsPage.tsx` & `0004_phase4_calls_memories_couple.sql`
- **Our Days Together:** Animated Years / Months / Days + total days counter from relationship start date.
- **Important Dates:** Birthdays, Anniversary, First Meeting, First Date, and custom dates with reminder lead-times (`important_dates` table).
- **Shared Notes:** Create, pin/unpin, and delete private shared notes (`shared_notes` table).
- **Daily Question:** Rotating couple prompts with private answers (`daily_questions` & `daily_answers` tables).
- **Love Notes:** Send romantic love notes with floating heart animations.
